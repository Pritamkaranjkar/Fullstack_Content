CSS Units

CSS units define the size of elements. The important thing is to understand what the unit is relative to.

1. px — Fixed

px gives a fixed size.

Example:
width: 200px;

The width stays 200px.

Use for: borders, icons and small elements where an exact size is needed.

Implementation
This box has width: 200px

2. % — Parent Based

% is usually relative to the parent.

Parent = 400px
width: 50%
50% of 400px = 200px

Use for: responsive widths, containers and images.

Implementation
50% of parent

3. em — Parent Font Based

em is based on the current/inherited font size.

Parent font-size = 16px
2em = 2 × 16px = 32px

Use for: components such as buttons where size should follow the text.

Implementation
2em → 32px

4. rem — Root Based

rem is based on the root <html> font size.

html font-size = 16px
2rem = 2 × 16px = 32px

Use for: headings, text sizes, margins and padding.

Implementation
2rem → 32px

5. vh — Viewport Height

vh is based on the browser's height.

1vh = 1% of screen height.
If screen = 800px:
50vh = 400px

Use for: hero sections and full-screen layouts.

Implementation
height: 15vh

6. vw — Viewport Width

vw is based on the browser's width.

1vw = 1% of screen width.
If screen = 1200px:
50vw = 600px

Use for: large responsive elements based on screen width.

Implementation
width: 40vw

Quick Remember

px → Fixed
% → Parent
em → Current/parent font size
rem → Root (html) font size
vh → Viewport height
vw → Viewport width
