Ways to Apply CSS

1. Inline CSS

This paragraph uses inline CSS.

Inline styles have high author-level precedence and can make large projects difficult to maintain. Prefer classes and external stylesheets for reusable design.

2. Internal CSS

This paragraph is styled by the <style> element in this HTML file.

3. External CSS

In a real project, common styles should normally be placed in a separate .css file and connected using <link>.

Example external stylesheet connection: <link rel="stylesheet" href="style.css">
