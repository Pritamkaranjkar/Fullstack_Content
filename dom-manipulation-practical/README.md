# DOM Manipulation Practical

This practical is divided into separate folders so each DOM concept can be studied and executed independently.

## Topics

01. Element Selection
02. Content Manipulation
03. Reading Input Values
04. CSS Manipulation
05. Class Manipulation
06. HTML Attributes
07. Creating Elements
08. Removing Elements
09. DOM Traversal
10. Events
11. Mouse Events
12. Keyboard Events
13. Form Handling
14. Event Bubbling
15. Event Delegation
16. Todo Project

## Folder structure

Each topic contains:

- `index.html` — HTML structure and example UI
- `style.css` — presentation
- `script.js` — DOM implementation with concise explanatory comments

## How to run

Open any topic folder and open its `index.html` in a browser.

Recommended order: 01 → 16.
