Topic 04 of 21

Conditions

Branching logic with if/else, switch, and the ternary operator.

NOTES.md

if / else if / else

if (score >= 90) {
  grade = "A";
} else if (score >= 75) {
  grade = "B";
} else {
  grade = "C";
}

switch

switch (day) {
  case "Sat":
  case "Sun":
    plan = "Weekend";
    break;
  default:
    plan = "Weekday";
}

Forgetting break lets execution "fall through" into the next case — sometimes intentional (as with Sat/Sun above), usually a bug.

Ternary

const label = age >= 18 ? "adult" : "minor";
