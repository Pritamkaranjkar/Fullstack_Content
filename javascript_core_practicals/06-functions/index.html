Functions

Declarations, expressions, arrow functions, default/rest parameters, callbacks and recursion.

NOTES.md

Three ways to write a function

function greet(name) { return `Hi ${name}`; }  // declaration, hoisted
const greet2 = function(name) { return `Hi ${name}`; }; // expression
const greet3 = (name) => `Hi ${name}`; // arrow function

Arrow functions don't have their own this — they inherit it from the surrounding scope, which is why they're popular for callbacks.

Default & rest parameters

function power(base, exp = 2) { return base ** exp; }
function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }

Callbacks & recursion

A callback is a function passed into another function to be called later. Recursion is a function that calls itself with a smaller input until it reaches a base case.
