javascript_core_practicals

21 practicals, one JavaScript engine.

A self-contained set of exercises taking JavaScript from var vs let all the way to classes, async/await and browser storage. Every folder has its own index.html, style.css and script.js — open any topic and run the interactive demos directly in the console pane.

01 JavaScript Fundamentals How JavaScript fits into a web page, how it runs, and the syntax rules everything else is built on. 02 Variables & Data Types Declaring storage with var, let and const, and the eight data types JavaScript values can hold. 03 Operators Arithmetic, comparison, logical and the modern nullish/optional-chaining operators. 04 Conditions Branching logic with if/else, switch, and the ternary operator. 05 Loops Repeating work with for, while, do-while, for...of, for...in, and controlling flow with break/continue. 06 Functions Declarations, expressions, arrow functions, default/rest parameters, callbacks and recursion. 07 Strings Template literals and the built-in methods for reading, searching and transforming text. 08 Arrays Storing ordered lists of data and the methods that create, transform and search them. 09 Objects Grouping related data and behaviour as key-value pairs, and the modern syntax for working with them. 10 Scope, Hoisting & Closures How JavaScript decides where a variable lives, why some declarations move, and how functions remember their birthplace. 11 DOM Manipulation Selecting, creating, editing and removing elements to change what the page displays. 12 Events Listening for user interaction, the event object, bubbling, and delegating events to a parent. 13 Forms & Validation Capturing form input, preventing default submission, and validating fields before they're used. 14 Modern JavaScript (ES6+) A tour of the syntax that modernised JavaScript: destructuring, spread/rest, template literals and more. 15 Asynchronous JavaScript Callbacks, Promises and async/await for work that finishes later — timers, network calls, files. 16 Fetch, JSON & APIs Requesting data from a server with fetch(), and converting between JavaScript objects and JSON text. 17 Modules Splitting code across files with import/export, so each file has a single responsibility. 18 Error Handling Catching problems gracefully with try/catch/finally, throwing your own errors, and error subclasses. 19 JavaScript Runtime The call stack, Web APIs, callback queue and microtask queue — how single-threaded JS handles async work. 20 Object-Oriented JavaScript Modeling data and behaviour with classes, inheritance, encapsulation and prototypes. 21 Browser Storage Persisting data in the browser with localStorage and sessionStorage.
