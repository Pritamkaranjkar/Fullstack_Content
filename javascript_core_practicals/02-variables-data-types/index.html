Topic 02 of 21

Variables & Data Types

Declaring storage with var, let and const, and the eight data types JavaScript values can hold.

NOTES.md

Declaring variables

var a = 1;   // function-scoped, hoisted, avoid in modern code
let b = 2;   // block-scoped, reassignable
const c = 3; // block-scoped, cannot be reassigned

const prevents reassignment of the binding, not mutation — a const array or object can still have its contents changed.

Primitive types

  • string — "hi", 'hi', `hi`
  • number — 42, 3.14, NaN, Infinity
  • bigint — 9007199254740993n, for integers beyond safe number range
  • boolean — true / false
  • undefined — declared, not yet assigned
  • null — deliberate "no value"
  • symbol — unique, mostly-hidden identifiers

Reference type

object (including arrays and functions) — stored by reference, not by value.

Type coercion

"5" + 1   // "51"  — number coerced to string
"5" - 1   // 4    — string coerced to number
