Fetch, JSON & APIs

Requesting data from a server with fetch(), and converting between JavaScript objects and JSON text.

NOTES.md

fetch basics

const res = await fetch(url);
if (!res.ok) throw new Error(`HTTP ${res.status}`);
const data = await res.json();

fetch only rejects on network failure — a 404 or 500 still resolves, so always check res.ok or res.status yourself.

JSON conversion

JSON.stringify(obj);  // JS value -> JSON string
JSON.parse(text);     // JSON string -> JS value

Sending data

fetch(url, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(payload)
});
