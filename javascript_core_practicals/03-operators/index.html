Operators

Arithmetic, comparison, logical and the modern nullish/optional-chaining operators.

NOTES.md

Arithmetic

+  -  *  /  %  **   // ** is exponent, % is remainder

Comparison

  • == loose equality — coerces types first (avoid)
  • === strict equality — no coercion (prefer this)
  • > < >= <= — ordering

Logical

&&  // AND — returns first falsy or last value
||  // OR  — returns first truthy or last value
!   // NOT

Modern operators

a ?? b        // nullish coalescing: b only if a is null/undefined
a?.b?.c       // optional chaining: stop safely if a or b is nullish
cond ? x : y  // ternary
