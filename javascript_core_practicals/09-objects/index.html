Topic 09 of 21

Objects

Grouping related data and behaviour as key-value pairs, and the modern syntax for working with them.

NOTES.md

Object literals

const user = {
  name: "Priya",
  age: 27,
  greet() { return `Hi, I'm ${this.name}`; }
};

Reading & writing

user.name;        // dot notation
user["name"];   // bracket notation (needed for dynamic keys)

Useful statics

  • Object.keys(obj), Object.values(obj), Object.entries(obj)
  • Object.assign({}, obj) / { ...obj } — shallow copy
  • Object.freeze(obj) — prevent changes

Destructuring & shorthand

const { name, age } = user;
const point = { x, y }; // shorthand when variable name === key
