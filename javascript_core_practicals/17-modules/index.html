Modules

Splitting code across files with import/export, so each file has a single responsibility.

NOTES.md

Exporting

// math.js
export function add(a, b) { return a + b; }
export const PI = 3.14159;
export default function multiply(a, b) { return a * b; }

Importing

// script.js
import multiply, { add, PI } from "./math.js";

Loading a module in HTML

<script type="module" src="script.js"></script>

Modules are deferred automatically, run in strict mode, and have their own scope — nothing leaks to the global object unless explicitly exported.
