Topic 10 of 21

Scope, Hoisting & Closures

How JavaScript decides where a variable lives, why some declarations move, and how functions remember their birthplace.

NOTES.md

Scope

  • Global scope — visible everywhere
  • Function scope — var is visible anywhere inside its function
  • Block scope — let/const are visible only inside { }

Hoisting

Declarations are processed before code runs. var declarations are hoisted and initialised to undefined; let/const are hoisted but stay in a Temporal Dead Zone until their line executes.

console.log(a); // undefined (not an error)
var a = 1;

console.log(b); // ReferenceError (TDZ)
let b = 2;

Closures

A closure is a function that remembers the variables from the scope it was created in, even after that outer function has returned.

function makeCounter() {
  let count = 0;
  return () => ++count; // closes over "count"
}
