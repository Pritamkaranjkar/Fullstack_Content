DOM Manipulation

Selecting, creating, editing and removing elements to change what the page displays.

NOTES.md

Selecting elements

document.querySelector(".card");      // first match
document.querySelectorAll(".card");    // NodeList of all matches
document.getElementById("main");

Creating & inserting

const li = document.createElement("li");
li.textContent = "New item";
list.appendChild(li);

Reading & writing content

  • el.textContent — safe text
  • el.innerHTML — parsed HTML (be careful with untrusted input)
  • el.setAttribute(), el.classList.add()/remove()/toggle()
  • el.style.property — inline styles

Removing

el.remove();
