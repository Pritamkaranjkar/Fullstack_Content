Loops

Repeating work with for, while, do-while, for...of, for...in, and controlling flow with break/continue.

NOTES.md

for

for (let i = 0; i < 5; i++) { ... }

while / do...while

while (condition) { ... }
do { ... } while (condition); // runs body at least once

for...of vs for...in

  • for...of — iterates values of an iterable (arrays, strings, Maps, Sets)
  • for...in — iterates enumerable keys of an object (avoid on arrays)

break & continue

break;    // exit the loop entirely
continue; // skip to the next iteration
