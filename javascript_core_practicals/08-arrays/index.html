Topic 08 of 21

Arrays

Storing ordered lists of data and the methods that create, transform and search them.

NOTES.md

Creating & accessing

const nums = [1, 2, 3];
nums[0];        // 1
nums.length;    // 3

Transforming (return new arrays)

  • map() — transform each item
  • filter() — keep items matching a condition
  • reduce() — fold into a single value
  • sort() — mutates in place, sorts as strings by default

Searching & iterating

  • find(), includes(), indexOf()
  • forEach() — run a callback per item, returns undefined

Destructuring & spread

const [first, second] = nums;
const copy = [...nums, 4];
