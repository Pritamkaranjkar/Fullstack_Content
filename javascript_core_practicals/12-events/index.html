Events

Listening for user interaction, the event object, bubbling, and delegating events to a parent.

NOTES.md

Listening for events

btn.addEventListener("click", (event) => {
  console.log(event.target);
});

The event object

  • event.target — the element that triggered the event
  • event.preventDefault() — stop default browser behaviour
  • event.stopPropagation() — stop it bubbling further up

Bubbling & delegation

Events fire on the target, then bubble up through its ancestors. Event delegation puts one listener on a parent and reads event.target, instead of attaching separate listeners to many children — efficient even for elements added later.

container.addEventListener("click", (e) => {
  if (e.target.matches("button")) { ... }
});
console — script.js

One listener on the container (event delegation) handles all three buttons above.
