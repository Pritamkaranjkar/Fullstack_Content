Forms & Validation

Capturing form input, preventing default submission, and validating fields before they're used.

NOTES.md

Preventing default submission

form.addEventListener("submit", (e) => {
  e.preventDefault(); // stop the full-page reload
});

Reading values

input.value
checkbox.checked
select.value

Validation approaches

  • Built-in HTML — required, pattern, minlength
  • Constraint Validation API — input.checkValidity(), input.validity
  • Custom JS logic — for rules HTML can't express (e.g. "passwords match")

Always validate on the server too — client-side validation is for user experience, not security.
