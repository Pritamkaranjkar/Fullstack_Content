Error Handling

Catching problems gracefully with try/catch/finally, throwing your own errors, and error subclasses.

NOTES.md

try / catch / finally

try {
  riskyOperation();
} catch (err) {
  console.error(err.message);
} finally {
  cleanup(); // always runs
}

Throwing your own errors

throw new Error("Something went wrong");

Built-in error types

  • TypeError — wrong type used (e.g. calling a non-function)
  • RangeError — number outside allowed range
  • ReferenceError — referencing an undeclared variable

Custom error classes

class ValidationError extends Error {
  constructor(msg) { super(msg); this.name = "ValidationError"; }
}
