Browser Storage

Persisting data in the browser with localStorage and sessionStorage.

NOTES.md

localStorage vs sessionStorage

  • localStorage — persists until explicitly cleared, shared across tabs
  • sessionStorage — cleared when the tab closes, isolated per tab

API (identical for both)

localStorage.setItem("key", value);   // value is coerced to a string
localStorage.getItem("key");
localStorage.removeItem("key");
localStorage.clear();

Storing objects

Storage only holds strings, so objects need JSON.stringify going in and JSON.parse coming out.

localStorage.setItem("user", JSON.stringify(user));
const user = JSON.parse(localStorage.getItem("user"));

Note: this demo page runs inside a sandboxed preview, so storage here is scoped to this document and clears more eagerly than in a normal browser tab — the API calls shown are identical to what you'd use on any live site.
